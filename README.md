 🧪 AQA Python — Автотесты логина (SauceDemo)

Проект выполнен в рамках технического задания на позицию **AQA Python**.

Сайт для тестирования: https://www.saucedemo.com/

---

 🚀 Используемые технологии

- 🐍 Python 3.10  
- 🎭 Playwright  
- 🧪 Pytest  
- 📊 Allure Report  
- 🧱 Page Object Model  

---

✅ Реализованные тесты

Покрыты **5 сценариев авторизации**:

1. ✅ Успешный логин  
   - `standard_user / secret_sauce`
2. ❌ Логин с неверным паролем
3. 🔒 Заблокированный пользователь  
   - `locked_out_user`
4. ⚠️ Логин с пустыми полями
5. 🐌 `performance_glitch_user`  
   - проверка корректного перехода с учётом возможных задержек

Все тесты успешно проходят, что подтверждено **Allure-отчётом**.

⚠️ Особенности и сложности проекта
🌍 Доступ к сайту

Сайт saucedemo.com недоступен из региона без VPN.

Для запуска тестов требовалось включение VPN на Windows.

🐍 Версия Python

Изначально в системе была установлена версия Python 3.14,
но она не соответствовала требованиям проекта.

Для корректной работы зависимостей была установлена и использована Python 3.10.

🐳 Docker (ограничения)

Dockerfile присутствует в проекте, однако полноценный запуск контейнера невозможен по следующим причинам:

используется урезанная версия Windows

Docker Desktop недоступен

связка WSL + VPN приводит к сетевым сбоям
сайт не открывается внутри контейнера без VPN
По этой причине тесты запускались локально на Windows.

📦 Установка и запуск

Установить Python 3.10

Создать виртуальное окружение

Установить зависимости:

pip install -r requirements.txt

Установить браузеры Playwright:

playwright install

Запустить тесты:

pytest
